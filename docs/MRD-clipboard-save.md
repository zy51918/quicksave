# QuickSave 剪切板保存功能 — 市场需求文档（MRD）

> 版本：4.0
> 日期：2026-04-29
> 作者：产品经理

---

## 一、产品概述

QuickSave 是一款 Android 工具类应用，让用户随时将剪切板中的文字保存到本地指定文件，每条记录自动附带时间戳和可选分类标签，方便日后查阅与归类。

---

## 二、目标用户

| 用户类型 | 典型场景 |
|---------|---------|
| 信息收集者 | 边读文章边随手保存摘录 |
| 研究 / 学习者 | 在多个 App 间摘录资料，统一归档到文本文件 |
| 效率工具用户 | 习惯使用纯文本文件管理笔记 |

---

## 三、核心用户故事

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-01 | 作为用户，我希望通知栏有一条**常驻通知**，点击可随时回到 QuickSave 应用。 | 应用运行期间通知栏始终显示该通知；点击可跳转至主页 |
| US-02 | 作为用户，我在主页点击**保存按钮**后，希望当前剪切板内容立即保存到指定文件。 | 点击后将剪切板文字追加写入目标文件，Snackbar 显示「已保存」 |
| US-03 | 作为用户，我希望每条保存记录**自动附带时间**，方便日后回溯。 | 保存格式：`[yyyy-MM-dd HH:mm:ss] 文字内容` |
| US-04 | 作为用户，我希望能在设置中**指定保存文件**，将内容归档到我习惯的位置。 | 调用系统文件选择器，可选择已有文件或新建文件；重启后权限保留 |
| US-05 | 作为用户，我希望能**一键清空保存文件**的全部内容，定期重新开始记录。 | 清空前有二次确认弹窗；确认后文件内容清空，Snackbar 反馈 |
| US-C01 | 作为用户，我希望保存时可以为内容**选择一个分类标签**。 | 主页剪切板卡片显示分类 Chip 行，选中后保存记录带分类前缀 |
| US-C02 | 作为用户，我希望**当前选中分类在重启后保留**，不必每次重新选择。 | 选中分类持久化到 DataStore，下次打开自动恢复 |
| US-C03 | 作为用户，我希望能在主页**快速新增分类**。 | Chip 行末尾「＋ 新增」弹 AlertDialog 输入名称，确认后追加并自动选中 |
| US-C04 | 作为用户，我希望能在设置页**完整管理分类**（增、删、改、排序）。 | 设置页「分类管理」区块支持新增、重命名、删除、拖拽排序 |
| US-C05 | 作为用户，我希望**不选分类时保存格式不变**，保持向后兼容。 | 无 Chip 选中时，保存格式与现有记录一致：`[时间戳] 内容` |

## 四、功能范围

### 4.1 必须有（MVP）

| 功能 | 描述 |
|------|------|
| 常驻通知 | 应用运行期间展示，点击跳转主页 |
| 主页保存按钮 | 读取当前剪切板内容并追加写入目标文件 |
| 时间戳记录 | 无分类时保存格式：`[yyyy-MM-dd HH:mm:ss] 文字` |
| 目标文件配置 | 通过系统 SAF 文件选择器选择或新建 .txt 文件 |
| 清空保存文件 | 一键截断文件内容，含二次确认 |

### 4.2 分类标签（v4.0 新增）

| 功能 | 描述 |
|------|------|
| 分类 Chip 选择器 | 主页剪切板卡片内横向可滚动 FilterChip 行，可切换或取消选中 |
| 带分类保存格式 | 选中分类时格式：`[分类名][yyyy-MM-dd HH:mm:ss] 文字` |
| 分类持久化 | 当前选中分类存入 DataStore，重启后自动恢复 |
| 主页快速新增分类 | Chip 行末尾「＋ 新增」弹窗输入，确认后追加并自动选中 |
| 分类管理（设置页） | 新增、重命名、删除、拖拽排序；删除/重命名同步更新 DataStore 中的 selectedCategory |

### 4.3 不在本期范围

- 剪切板自动监听 / 悬浮按钮
- 云同步 / 多设备共享
- 图片剪切板支持
- 多文件目标管理
- 应用内历史记录查看
- 按分类筛选历史记录
- 修改已保存记录的分类
- 分类颜色或图标自定义
- 多选分类

## 五、交互流程

### 流程 A：保存剪切板内容（主路径）

```
用户在其他 App 复制文字
       ↓
点击通知栏中的常驻通知
       ↓
跳转到 QuickSave 主页
       ↓
主页展示当前剪切板内容预览
       ↓
（可选）在 Chip 行选择或切换分类
       ↓
用户点击「保存」按钮
       ↓
文字 + 时间戳（+ 分类前缀）追加写入目标文件
       ↓
Snackbar 显示「已保存」
```

### 流程 B：配置目标文件

```
进入设置页
       ↓
点击「选择保存文件」
       ↓
系统文件选择器
       ↓
选择已有 .txt 文件 或 新建文件（默认名 quicksave.txt）
       ↓
返回设置页，显示当前文件路径
```

### 流程 D：管理分类（设置页）

```
进入设置页
       ↓
「分类管理」区块显示分类列表
       ↓
可新增 / 重命名 / 删除 / 拖拽排序
       ↓
操作实时写入 DataStore
```

### 流程 C：清空保存文件

```
主页点击「清空文件内容」
       ↓
弹出确认对话框
       ↓
确认后文件内容清空
       ↓
Snackbar 显示「文件内容已清空」
```

## 六、边界条件 & 异常处理

| 场景 | 期望行为 |
|------|---------|
| 剪切板为空 | 保存按钮禁用或提示「剪切板为空」 |
| 未配置目标文件 | 主页提示引导用户前往设置选择文件 |
| SAF 权限丢失（重启后） | 保存时提示「文件无写入权限，请重新选择」 |
| 文件写入失败 | Snackbar 显示具体错误信息 |
| 分类名为空 | 新增/重命名对话框「确定」按钮禁用 |
| 分类名与已有重复 | 对话框显示内联错误「分类名已存在」 |
| 删除当前选中分类 | selectedCategory 同步重置为 null |
| 重命名当前选中分类 | selectedCategory 同步更新为新名称 |
| selectedCategory 不在列表中 | 读取时视为 null，不崩溃 |
| 分类列表为空 | 设置页显示「暂无分类，点击下方按钮添加」；主页 Chip 行仅显示「＋ 新增」 |

## 七、非功能性需求

| 项目 | 要求 |
|------|------|
| 最低 Android 版本 | Android 10（API 29） |
| 文件格式 | 纯文本，UTF-8，换行分隔；记录格式 `[分类][时间戳] 内容` 或 `[时间戳] 内容` |
| 权限最小化 | 仅申请功能必须的权限 |
| DataStore 存储 | 分类列表以换行符分隔序列化；分类名不含换行符 |
