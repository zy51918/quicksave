## 一、需求背景与用户痛点

用户经常需要把多个 App 中复制到的零碎文字（金句、参考资料、网址、片段笔记）归档成一份长期可查的本地文件。

现有方案的痛点：
- **笔记 App 太重**：打开 → 新建条目 → 粘贴 → 保存，至少 4 步，且常常无法附时间。
- **直接保存到文件**需要先开文件管理器，再用编辑器追加，操作复杂、容易丢失上下文。
- **云端剪贴板工具**有隐私顾虑，且依赖网络。

**MVP 的核心承诺**：复制完成后，用户最多 3 步把内容连同时间戳追加到自己指定的本地纯文本文件里。

---

## 二、目标用户

| 用户类型 | 典型场景 |
|---------|---------|
| 信息收集者 | 边读文章边随手保存摘录 |
| 研究 / 学习者 | 在多个 App 间摘录资料，统一归档到一份纯文本 |
| 效率工具用户 | 习惯用纯文本文件管理笔记，希望追加式记录带时间 |

## 三、用户故事

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-01 | 作为用户，我希望通知栏有一条**常驻通知**，点击可随时回到 QuickSave 应用。 | 应用运行期间通知栏始终显示该通知；点击跳转主页 |
| US-02 | 作为用户，我在主页点击**保存按钮**后，希望当前剪切板内容立即保存到指定文件。 | 点击后将剪切板文字追加写入目标文件，Snackbar 显示「已保存」 |
| US-03 | 作为用户，我希望每条保存记录**自动附带时间**，方便日后回溯。 | 保存格式：`[yyyy-MM-dd HH:mm:ss] 文字内容`，按行追加 |
| US-04 | 作为用户，我希望能在设置中**指定保存文件**，将内容归档到我习惯的位置。 | 调用系统文件选择器，可选择已有文件或新建文件；重启后权限保留 |
| US-05 | 作为用户，我希望能**一键清空保存文件**的全部内容，定期重新开始记录。 | 清空前有二次确认弹窗；确认后文件内容清空，Snackbar 反馈 |

## 四、功能范围

### 4.1 已交付

| 功能 | 描述 |
|------|------|
| 常驻通知 | 应用运行期间展示，点击跳转主页 |
| 主页保存按钮 | 读取当前剪切板内容并追加写入目标文件 |
| 时间戳记录 | 保存格式：`[yyyy-MM-dd HH:mm:ss] 文字`，按行追加 |
| 目标文件配置 | 通过系统 SAF 文件选择器选择或新建 .txt 文件，重启后权限保留 |
| 清空保存文件 | 一键截断文件内容，含二次确认 |

### 4.2 不在 MVP 范围

- 任何形式的分类 / 标签（已交付于 `category-tag` feature，详见 §七 演进）
- 剪切板自动监听 / 悬浮按钮
- 云同步 / 多设备共享
- 图片或富文本剪切板
- 多文件目标管理
- 应用内历史记录浏览

## 五、交互流程

### 流程 A：保存剪切板内容（主路径）

```
用户在其他 App 复制文字
       ↓
点击通知栏中的常驻通知
       ↓
跳转到 QuickSave 主页（展示当前剪切板预览）
       ↓
点击「保存」按钮
       ↓
文字 + 时间戳追加写入目标文件
       ↓
Snackbar 显示「已保存」
```

### 流程 B：配置目标文件

```
进入设置页
       ↓
点击「选择保存文件」
       ↓
系统文件选择器
       ↓
选择已有 .txt 文件 或 新建文件（默认名 quicksave.txt）
       ↓
返回设置页，显示当前文件路径
```

### 流程 C：清空保存文件

```
主页点击「清空文件内容」
       ↓
弹出确认对话框
       ↓
确认后文件内容清空
       ↓
Snackbar 显示「文件内容已清空」
```

## 六、边界条件 & 异常处理

| 场景 | 期望行为 |
|------|---------|
| 剪切板为空 | 保存按钮禁用或提示「剪切板为空」 |
| 未配置目标文件 | 主页提示引导用户前往设置选择文件 |
| SAF 权限丢失（如系统重启 / 用户撤销） | 保存时提示「文件无写入权限，请重新选择」 |
| 文件写入失败（IO 异常、空间不足） | Snackbar 显示具体错误信息，不静默失败 |
| 剪切板内容过长 | 主页预览裁剪显示，但完整内容写入文件 |
| 清空操作误触 | 必须经过二次确认对话框，主操作按钮以红色区分 |

## 八、非功能性需求

| 项目 | 要求 |
|------|------|
| 最低 Android 版本 | Android 10（API 29） |
| 文件格式 | 纯文本，UTF-8，换行分隔；MVP 行格式 `[时间戳] 内容` |
| 权限最小化 | 仅申请功能必须的权限（前台服务通知、SAF 文件读写） |
| 隐私 | 剪切板内容不上传任何网络；目标文件由用户自选位置 |

---

## 九、成功指标

| 指标 | 目标 |
|------|------|
| 操作步骤数 | 从「复制完成」到「文件已落盘」≤ 3 步操作 |
| 文件写入可靠性 | 权限正常情况下成功率 100% |
| 应用冷启动到主页可保存 | ≤ 2 秒（中端机型） |
