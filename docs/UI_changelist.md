# UI Changelist

## [2026-09-23] [全项目][图标] 应用图标背景由品牌浅绿 `#C5E166` 改为**白色**。白底与深色文档形成 14.93:1 的强轮廓，比浅绿底更稳，也避免浅绿主色在启动器里与相邻图标抢色。同步把文档投影从 `#2D370B`@55%（配浅绿底调的橄榄色，落白底发黄绿显脏）改为中性墨色 `#102A36`@18%。项目级 UI 新增 §2.4 应用图标规范（此前一直缺，图标配色未进文档）。已实机截图（应用信息页 + 放大取样）确认渲染结果。

## [2026-09-23] [主页][控件] 「清空保存文件内容」改为单个全宽 `OutlinedButton`（Error 色，图标 + 文案居中），去掉原先右侧重复的「清空」`TextButton`。原实现是「Surface 容器 + 左图标文字 + 右 TextButton」，同一操作出现两处文字；现按 §3.1 既定规格（文档一直写的是 OutlinedButton）改回按钮形态，描边由按钮自身提供。新增 `appDangerOutlinedButtonColors()`（`ui/theme/ComponentColors.kt`）承载危险操作配色，与品牌强调色区分。

## [2026-09-23] [全项目][扁平化] 主页**分类框**与**手动记录卡**去掉 1dp `outlineVariant` 描边，改为无边框、无阴影的纯扁平卡片（项目级 UI 升 v1.9）。目的是与主色改造后的浅绿填充风格统一，减少线框。卡片与页面底对比度仅 1.08:1（`#FFFFFF` vs `#F4F7F7`），边界改由留白与分区标题（`FROM CLIPBOARD` / `OR WRITE IT HERE`）划分。**保留描边**：「清空保存文件内容」条（危险操作需独立可点区域边界）、Chip 与输入框等控件级描边。已实机截图确认渲染结果（卡片边缘单像素内完成白→底跃迁，无渐变带）。同步更新 `quick-save-redesign.svg` 与 `overlay-clipboard-save.svg` 两个原型。

## [2026-09-23] [全项目][配色] 品牌主色改为浅绿，色号 `#B5E61D` → `#C5E166`（项目级 UI 升 v1.8）。因该色亮度极高（白字在其上仅 1.46:1、它作小字落在 Paper 上仅 1.36:1），确立硬规则「主色只作填充，绝不作文字/描边」，并派生三个配套 token：`LimeInk #2D370B`（主色填充之上的文字/图标，8.62:1）、`LimeDark #465511`（浅色底上的主色文字与描边，Paper 上 7.28:1）、`LimePale #EDF6D0`（浅色容器底）。三者与新主色同色相（H≈74°）同饱和度（S≈67%），仅明度不同，故整体协调。代码层新增 `MaterialTheme.brandColors.accent`（`ui/theme/Theme.kt`），承接 M3 `primary` 语义覆盖不到的"浅底上的主色文字/描边"用法：浅色主题取 `#465511`、深色主题取 `#C5E166`。改动覆盖：主题两套 ColorScheme（含深色次要色 `#C9E370`）、主页（eyebrow、"＋新增" Chip、剪切板卡图标块与按钮、副文字透明度 72%→90%）、设置页 eyebrow、悬浮窗动作按钮与面板内容色、启动图标（背景 `#005A58`→`#C5E166`，文档主体转深色 `#102A36` 以免与背景糊在一起）、iOS 侧色板与视图（选中 Chip 文字由白色改为深色、SaveButton 显式指定前景色）、以及全部 mockup 原型。文档同步：§2.1 重写色彩系统、§3.1/§3.2/§3.3 规格更新、§6.2/§6.3 iOS 反馈色更新。**修复（同批次）**：首轮只改了主色填充处，遗漏了 M3 默认拿 `primary` 当**前景色**的组件 —— 设置页「重新选择文件」「＋ 新增分类」`OutlinedButton`、「重命名」`TextButton`，以及主页的「去选择文件」`OutlinedButton`、手动输入卡与分类对话框的 `OutlinedTextField`、清空对话框的 `TextButton`，这些在新配色下文字/描边落在 Paper 上仅 1.36:1，几乎不可见，且与主页已有的 accent 用法不一致。新增 `ui/theme/ComponentColors.kt`（`appOutlinedButtonColors` / `appTextButtonColors` / `appOutlinedTextFieldColors`），两页共用统一收口；`Switch` 选中态用 `onPrimary` 作滑块色（深色），不受影响，未改动。
