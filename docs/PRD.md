# QuickSave — 产品需求文档（PRD）

> 版本：1.3
> 日期：2026-06-11
> 作者：产品经理

---

## 一、产品概述

QuickSave 是一款 Android 工具类应用，让用户随时将剪切板中的文字保存到本地指定文件，每条记录自动附带时间戳和可选分类标签，方便日后查阅与归类。

**核心价值主张：** 零摩擦、一键归档。复制即保存，打开即完成。

---

## 二、目标用户

| 用户类型 | 典型场景 |
|---------|---------|
| 信息收集者 | 边读文章边随手保存摘录 |
| 研究 / 学习者 | 在多个 App 间摘录资料，统一归档到文本文件 |
| 效率工具用户 | 习惯使用纯文本文件管理笔记，需要按主题分类 |

## 三、用户故事

### 3.1 核心功能

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-01 | 作为用户，我希望通知栏有一条**常驻通知**，点击可随时回到 QuickSave 应用。 | 应用运行期间通知栏始终显示该通知；点击跳转主页 |
| US-02 | 作为用户，我在主页点击**保存按钮**后，希望当前剪切板内容立即保存到指定文件。 | 点击后将剪切板文字追加写入目标文件，Snackbar 显示「已保存」 |
| US-03 | 作为用户，我希望每条保存记录**自动附带时间**，方便日后回溯。 | 无分类时保存格式：`[yyyy-MM-dd HH:mm:ss] 文字内容` |
| US-04 | 作为用户，我希望能在设置中**指定保存文件**，将内容归档到我习惯的位置。 | 调用系统文件选择器，可选择已有文件或新建文件；重启后权限保留 |
| US-05 | 作为用户，我希望能**一键清空保存文件**的全部内容，定期重新开始记录。 | 清空前有二次确认弹窗；确认后文件内容清空，Snackbar 反馈 |

### 3.2 分类标签

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-C01 | 作为用户，我希望保存时可以为内容**选择一个分类标签**。 | 主页剪切板卡片显示分类 Chip 行，选中后保存记录带分类前缀 |
| US-C02 | 作为用户，我希望**当前选中分类在重启后保留**，不必每次重新选择。 | 选中分类持久化到 DataStore，下次打开自动恢复 |
| US-C03 | 作为用户，我希望能在主页**快速新增分类**。 | Chip 行末尾「＋ 新增」弹 AlertDialog 输入名称，确认后追加并自动选中 |
| US-C04 | 作为用户，我希望能在设置页**完整管理分类**（增、删、改、排序）。 | 设置页「分类管理」区块支持新增、重命名、删除、拖拽排序 |
| US-C05 | 作为用户，我希望**不选分类时保存格式不变**，保持向后兼容。 | 无 Chip 选中时，保存格式与现有记录一致：`[时间戳] 内容` |

### 3.3 手动输入保存（QS-0002）

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-M01 | 作为用户，我希望在主页有一个**多行输入框**，可以直接输入想保存的文字。 | 主页可见多行 TextField，3 行可见高度，placeholder「在此输入要保存的文字」 |
| US-M02 | 作为用户，我希望输入完成后点击**保存按钮**，立即将文字按现有格式追加写入目标文件。 | 文字（含可选分类前缀和时间戳）追加写入；Snackbar「已保存」 |
| US-M03 | 作为用户，我希望保存前可以**选择一个分类标签**，与剪切板保存共用同一组分类。 | 主页顶部共享 Chip 行，选中分类后保存格式带分类前缀 |
| US-M04 | 作为用户，我希望保存成功后**输入框自动清空**，分类选中保留。 | 成功后 TextField 回到空状态；selectedCategory 不变 |
| US-M05 | 作为用户，我希望**输入框为空（含纯空白）时无法保存**。 | 空或纯空白时保存按钮禁用 |
| US-M06 | 作为用户，我希望**输入内容在屏幕旋转时不丢失**，强杀后无需保留。 | 配置变更通过 ViewModel `StateFlow` 自然保留；进程被杀后丢失 |

### 3.4 全局悬浮窗（QS-0003）

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-F01 | 作为用户，我希望在设置页有一个**总开关**启用全局悬浮窗。 | 开启时若未授予「显示在其他应用上层」权限则跳系统授权页；授予后悬浮窗常驻，关闭后立即消失；开关状态持久化 |
| US-F02 | 作为用户，我希望悬浮窗**贴边显示一个半透明把手**，叠加在所有 App 之上。 | 把手常驻屏幕左/右边缘，可上下拖动改位置、可跨边切换；位置（边+高度比例）持久化，重开 App 恢复 |
| US-F03 | 作为用户，我希望**点击把手展开**一个横排快捷面板，操作完或点面板外自动收起。 | 点把手展开横排 2 按钮面板（文字输入 / 录音）；点按钮或点面板外区域收回贴边 |
| US-F04 | 作为用户，我希望点面板的**【文字输入】**弹出与主页一致的输入框直接保存。 | 拉起透明输入窗，含分类 Chip 行 + 多行输入框 + 保存按钮（复用主页手动输入）；保存成功 Toast「已保存」并关闭 |
| US-F05 | 作为用户，我希望点面板的**【录音】立即开始录音，再次点击停止**。 | 首次需授予麦克风权限；录音写入 `Music/QuickSave/QS_<时间戳>.m4a`；再次点击或通知「停止」结束并落盘 |
| US-F06 | 作为用户，我希望**录音期间切换 App 或锁屏都不中断**。 | 录音由前台服务承载，跨 App / 锁屏持续；系统抢占（来电等）时停止并保留已录片段 |
| US-F07 | 作为用户，我希望**录音中悬浮窗有明显状态提示**。 | 收起态把手变红 + 红点；展开态录音按钮变红并显示计时 `录音中 mm:ss`（计时不引起面板抖动） |

### 4.4 已交付（全局悬浮窗 v1.3 — QS-0003）

| 功能 | 描述 |
|------|------|

| 常驻贴边悬浮窗 | 半透明把手叠加于所有 App 之上，可拖拽沿边定位、自动吸附最近边；位置持久化 |
| 横排快捷面板 | 点把手展开 2 按钮（文字输入 / 录音），点按钮或点面板外收回 |
| 悬浮窗文字输入 | 透明 `InputActivity` 复用主页手动输入（分类 Chip + 输入框 + 保存），共用同一目标文件与格式 |
| 悬浮窗录音 | `microphone` 前台服务 + `MediaRecorder` 录制，落盘 `Music/QuickSave/QS_<时间戳>.m4a`（AAC/MPEG-4）；toggle 启停、防中断 |
| 录音态可视化 | 收起态把手变红+红点；展开态录音按钮变红显示计时（固定宽+等宽数字，不抖动） |

> 设计文档：[`docs/features/QS-0003/design-floating-window.md`](features/QS-0003/design-floating-window.md) · 发布于 v1.3（2026-06-11）
> 单条常驻通知：悬浮窗服务降级为非前台、由剪贴板常驻服务保活，应用常驻通知收成一条；录音时临时增加一条录音通知，停止即消失。

### 4.5 不在当前范围

- 剪切板自动监听（复制即自动保存）
- 悬浮窗自定义按钮（用户自定义 toggle / 启动其他 App）
- 录音波形、暂停 / 继续、最大时长限制
- 开机自启（重启后需重开 App 恢复服务与悬浮窗）
- 云同步 / 多设备共享
- 图片剪切板支持
- 多文件目标管理
- 应用内历史记录查看 / 按分类筛选 / 修改已保存记录分类
- 分类颜色或图标自定义、多选分类
- 手动输入草稿跨进程持久化（被强杀后保留）

## 五、交互流程

### 流程 A：保存剪切板内容（主路径）

```
用户在其他 App 复制文字
       ↓
点击通知栏中的常驻通知
       ↓
跳转到 QuickSave 主页
       ↓
主页展示当前剪切板内容预览
       ↓
（可选）在 Chip 行选择或切换分类
       ↓
用户点击「保存」按钮
       ↓
文字 + 时间戳（+ 分类前缀）追加写入目标文件
       ↓
Snackbar 显示「已保存」
```

### 流程 B：配置目标文件

```
进入设置页
       ↓
点击「选择保存文件」
       ↓
系统文件选择器
       ↓
选择已有 .txt 文件 或 新建文件（默认名 quicksave.txt）
       ↓
返回设置页，显示当前文件路径
```

### 流程 C：清空保存文件

```
主页点击「清空文件内容」
       ↓
弹出确认对话框
       ↓
确认后文件内容清空
       ↓
Snackbar 显示「文件内容已清空」
```

### 流程 D：管理分类（设置页）

```
进入设置页
       ↓
「分类管理」区块显示分类列表
       ↓
可新增 / 重命名 / 删除 / 拖拽排序
       ↓
操作实时写入 DataStore
```

### 流程 E：悬浮窗文字输入（QS-0003）

```
在任意 App 点击贴边把手
       ↓
展开横排面板 → 点【文字输入】
       ↓
面板收回，拉起透明输入窗（分类 Chip + 输入框）
       ↓
输入文字（可选分类）→ 点保存
       ↓
追加写入目标文件 → Toast「已保存」→ 输入窗关闭
```

### 流程 F：悬浮窗录音（QS-0003）

```
点击把手展开 → 点【录音】
       ↓
（首次）申请麦克风权限
       ↓
开始录音：把手变红+红点，通知显示计时与「停止」
       ↓
（切 App / 锁屏不中断）
       ↓
再次点【录音】或通知「停止」
       ↓
落盘 Music/QuickSave/QS_<时间戳>.m4a → Toast「录音已保存」
```

## 六、边界条件 & 异常处理

| 场景 | 期望行为 |
|------|---------|
| 剪切板为空 | 保存按钮禁用或提示「剪切板为空」 |
| 未配置目标文件 | 主页提示引导用户前往设置选择文件 |
| SAF 权限丢失（重启后） | 保存时提示「文件无写入权限，请重新选择」 |
| 文件写入失败 | Snackbar 显示具体错误信息 |
| 分类名为空 | 新增/重命名对话框「确定」按钮禁用 |
| 分类名与已有重复 | 对话框显示内联错误「分类名已存在」 |
| 删除当前选中分类 | selectedCategory 同步重置为 null |
| 重命名当前选中分类 | selectedCategory 同步更新为新名称 |
| selectedCategory 不在列表中 | 读取时视为 null，不崩溃 |
| 分类列表为空 | 设置页显示「暂无分类，点击下方按钮添加」；主页 Chip 行仅显示「＋ 新增」 |
| 未授予悬浮窗权限就开总开关 | 跳系统授权页；返回仍未授权则总开关回弹 |
| 悬浮窗权限被系统撤销（开关仍为开） | 进设置页时自动对账，将开关回退为关 |
| 录音权限被拒 | Toast「需要麦克风权限才能录音」，不进入录音态 |
| 麦克风被占用 / 录音启动失败 | Toast 提示，不进入录音态 |
| 录音中被系统抢占（来电等） | 停止录制并保留已录片段 |
| 把手拖出屏幕 | 限制在可视范围，松手吸附最近左/右边 |

## 七、非功能性需求

| 项目 | 要求 |
|------|------|
| 最低 Android 版本 | Android 10（API 29） |
| 文件格式 | 纯文本，UTF-8，换行分隔；格式 `[分类][时间戳] 内容` 或 `[时间戳] 内容` |
| 录音格式 | AAC / MPEG-4 容器（`.m4a`），经 MediaStore 存入公共 `Music/QuickSave/` |
| 权限最小化 | 仅申请功能必须的权限（悬浮窗、录音为对应功能开启时才申请） |
| 常驻通知 | 应用常驻通知保持**一条**；录音期间临时增加一条录音通知 |
| DataStore 存储 | 分类列表以换行符分隔序列化；分类名不含换行符 |

| 指标 | 目标 |
|------|------|
| 核心流程步骤 | 从复制到保存完成，操作步骤 ≤ 3 步 |
