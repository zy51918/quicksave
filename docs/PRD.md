# QuickSave — 产品需求文档（PRD）

> 版本：1.2
> 日期：2026-05-08
> 作者：产品经理

---

## 一、产品概述

QuickSave 是一款 Android 工具类应用，让用户随时将剪切板中的文字保存到本地指定文件，每条记录自动附带时间戳和可选分类标签，方便日后查阅与归类。

**核心价值主张：** 零摩擦、一键归档。复制即保存，打开即完成。

---

## 二、目标用户

| 用户类型 | 典型场景 |
|---------|---------|
| 信息收集者 | 边读文章边随手保存摘录 |
| 研究 / 学习者 | 在多个 App 间摘录资料，统一归档到文本文件 |
| 效率工具用户 | 习惯使用纯文本文件管理笔记，需要按主题分类 |

## 三、用户故事

### 3.1 核心功能

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-01 | 作为用户，我希望通知栏有一条**常驻通知**，点击可随时回到 QuickSave 应用。 | 应用运行期间通知栏始终显示该通知；点击跳转主页 |
| US-02 | 作为用户，我在主页点击**保存按钮**后，希望当前剪切板内容立即保存到指定文件。 | 点击后将剪切板文字追加写入目标文件，Snackbar 显示「已保存」 |
| US-03 | 作为用户，我希望每条保存记录**自动附带时间**，方便日后回溯。 | 无分类时保存格式：`[yyyy-MM-dd HH:mm:ss] 文字内容` |
| US-04 | 作为用户，我希望能在设置中**指定保存文件**，将内容归档到我习惯的位置。 | 调用系统文件选择器，可选择已有文件或新建文件；重启后权限保留 |
| US-05 | 作为用户，我希望能**一键清空保存文件**的全部内容，定期重新开始记录。 | 清空前有二次确认弹窗；确认后文件内容清空，Snackbar 反馈 |

### 3.2 分类标签

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-C01 | 作为用户，我希望保存时可以为内容**选择一个分类标签**。 | 主页剪切板卡片显示分类 Chip 行，选中后保存记录带分类前缀 |
| US-C02 | 作为用户，我希望**当前选中分类在重启后保留**，不必每次重新选择。 | 选中分类持久化到 DataStore，下次打开自动恢复 |
| US-C03 | 作为用户，我希望能在主页**快速新增分类**。 | Chip 行末尾「＋ 新增」弹 AlertDialog 输入名称，确认后追加并自动选中 |
| US-C04 | 作为用户，我希望能在设置页**完整管理分类**（增、删、改、排序）。 | 设置页「分类管理」区块支持新增、重命名、删除、拖拽排序 |
| US-C05 | 作为用户，我希望**不选分类时保存格式不变**，保持向后兼容。 | 无 Chip 选中时，保存格式与现有记录一致：`[时间戳] 内容` |

### 3.3 手动输入保存（QS-0002）

| # | 用户故事 | 验收条件 |
|---|---------|---------|
| US-M01 | 作为用户，我希望在主页有一个**多行输入框**，可以直接输入想保存的文字。 | 主页可见多行 TextField，3 行可见高度，placeholder「在此输入要保存的文字」 |
| US-M02 | 作为用户，我希望输入完成后点击**保存按钮**，立即将文字按现有格式追加写入目标文件。 | 文字（含可选分类前缀和时间戳）追加写入；Snackbar「已保存」 |
| US-M03 | 作为用户，我希望保存前可以**选择一个分类标签**，与剪切板保存共用同一组分类。 | 主页顶部共享 Chip 行，选中分类后保存格式带分类前缀 |
| US-M04 | 作为用户，我希望保存成功后**输入框自动清空**，分类选中保留。 | 成功后 TextField 回到空状态；selectedCategory 不变 |
| US-M05 | 作为用户，我希望**输入框为空（含纯空白）时无法保存**。 | 空或纯空白时保存按钮禁用 |
| US-M06 | 作为用户，我希望**输入内容在屏幕旋转时不丢失**，强杀后无需保留。 | 配置变更通过 ViewModel `StateFlow` 自然保留；进程被杀后丢失 |

## 四、功能范围

### 4.1 已交付（MVP）

| 功能 | 描述 |
|------|------|
| 常驻通知 | 应用运行期间展示，点击跳转主页 |
| 主页保存按钮 | 读取当前剪切板内容并追加写入目标文件 |
| 时间戳记录 | 无分类时保存格式：`[yyyy-MM-dd HH:mm:ss] 文字` |
| 目标文件配置 | 通过系统 SAF 文件选择器选择或新建 .txt 文件 |
| 清空保存文件 | 一键截断文件内容，含二次确认 |

### 4.2 已交付（分类标签 v1.1）

| 功能 | 描述 |
|------|------|
| 分类 Chip 选择器 | 主页剪切板卡片内横向可滚动 FilterChip 行，可切换或取消选中 |
| 带分类保存格式 | 选中分类时格式：`[分类名][yyyy-MM-dd HH:mm:ss] 文字` |
| 分类持久化 | 当前选中分类存入 DataStore，重启后自动恢复 |
| 主页快速新增分类 | Chip 行末尾「＋ 新增」弹窗输入，确认后追加并自动选中 |
| 分类管理（设置页） | 新增、重命名、删除、拖拽排序；删除/重命名同步更新 DataStore 中的 selectedCategory |

### 4.3 已交付（手动输入保存 v1.2 — QS-0002）

| 功能 | 描述 |
|------|------|
| 主页手动输入框 | 多行 TextField，3 行可见，超出滚动；placeholder「在此输入要保存的文字」 |
| 手动输入保存按钮 | 输入非空（去空白后）时启用；与剪切板保存路径并存，互不干扰 |
| 共享分类 Chip 行 | Chip 行从剪切板卡内移出置顶，剪切板和手动输入两路保存共用 `selectedCategory` |
| 共享文件与格式 | 复用同一目标文件与保存格式 `[分类][时间戳] 内容` / `[时间戳] 内容` |

> 详见 [`docs/features/QS-0002/prd-manual-input.md`](features/QS-0002/prd-manual-input.md) · 发布于 v1.2（2026-05-08）

### 4.4 不在当前范围

- 剪切板自动监听 / 悬浮按钮
- 云同步 / 多设备共享
- 图片剪切板支持
- 多文件目标管理
- 应用内历史记录查看
- 按分类筛选历史记录
- 修改已保存记录的分类
- 分类颜色或图标自定义
- 多选分类
- 手动输入草稿跨进程持久化（被强杀后保留）

## 五、交互流程

### 流程 A：保存剪切板内容（主路径）

```
用户在其他 App 复制文字
       ↓
点击通知栏中的常驻通知
       ↓
跳转到 QuickSave 主页
       ↓
主页展示当前剪切板内容预览
       ↓
（可选）在 Chip 行选择或切换分类
       ↓
用户点击「保存」按钮
       ↓
文字 + 时间戳（+ 分类前缀）追加写入目标文件
       ↓
Snackbar 显示「已保存」
```

### 流程 B：配置目标文件

```
进入设置页
       ↓
点击「选择保存文件」
       ↓
系统文件选择器
       ↓
选择已有 .txt 文件 或 新建文件（默认名 quicksave.txt）
       ↓
返回设置页，显示当前文件路径
```

### 流程 C：清空保存文件

```
主页点击「清空文件内容」
       ↓
弹出确认对话框
       ↓
确认后文件内容清空
       ↓
Snackbar 显示「文件内容已清空」
```

### 流程 D：管理分类（设置页）

```
进入设置页
       ↓
「分类管理」区块显示分类列表
       ↓
可新增 / 重命名 / 删除 / 拖拽排序
       ↓
操作实时写入 DataStore
```

## 六、边界条件 & 异常处理

| 场景 | 期望行为 |
|------|---------|
| 剪切板为空 | 保存按钮禁用或提示「剪切板为空」 |
| 未配置目标文件 | 主页提示引导用户前往设置选择文件 |
| SAF 权限丢失（重启后） | 保存时提示「文件无写入权限，请重新选择」 |
| 文件写入失败 | Snackbar 显示具体错误信息 |
| 分类名为空 | 新增/重命名对话框「确定」按钮禁用 |
| 分类名与已有重复 | 对话框显示内联错误「分类名已存在」 |
| 删除当前选中分类 | selectedCategory 同步重置为 null |
| 重命名当前选中分类 | selectedCategory 同步更新为新名称 |
| selectedCategory 不在列表中 | 读取时视为 null，不崩溃 |
| 分类列表为空 | 设置页显示「暂无分类，点击下方按钮添加」；主页 Chip 行仅显示「＋ 新增」 |

## 七、非功能性需求

| 项目 | 要求 |
|------|------|
| 最低 Android 版本 | Android 10（API 29） |
| 文件格式 | 纯文本，UTF-8，换行分隔；格式 `[分类][时间戳] 内容` 或 `[时间戳] 内容` |
| 权限最小化 | 仅申请功能必须的权限 |
| DataStore 存储 | 分类列表以换行符分隔序列化；分类名不含换行符 |

## 八、成功指标

| 指标 | 目标 |
|------|------|
| 核心流程步骤 | 从复制到保存完成，操作步骤 ≤ 3 步 |
